prototype returns what it does
void Main() void Creates the board. Runs the game loop: print → prompt → validate → place → check win/draw → swap player.
void PrintBoard(int[,] board) void Renders the current board state to the console, mapping 1→X, −1→O, 0→dot.
int CheckWinner(int[,] board) int Orchestrates win detection. Loops 0–2 calling CheckRow and CheckColumn, then calls CheckDiagonals once. Returns 1, −1, or 0.
int CheckRow(int[,] board, int row) int Sums the three cells in the given row. Returns 1 if X wins, −1 if O wins, 0 otherwise.
int CheckColumn(int[,] board, int col) int Sums the three cells in the given column. Returns 1 if X wins, −1 if O wins, 0 otherwise.
int CheckDiagonals(int[,] board) int Sums both diagonals. Returns 1 if X wins, −1 if O wins, 0 if neither diagonal is complete.
bool IsBoardFull(int[,] board) bool Scans every cell; returns true only when no cell equals 0. Used to detect a draw after CheckWinner returns 0.
