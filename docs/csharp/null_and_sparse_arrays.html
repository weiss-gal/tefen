null במערכים — מערך דליל ומערך צפוף

C# · רמת מתחילים–בינוניים

1. null ב-C# — תזכורת

null הוא ערך מיוחד שמשמעותו: "אין כאן אובייקט". הוא שייך לטיפוסי הפניה (reference types) — כמו מחלקות (class). מספרים (int, double) אינם יכולים להיות null — ניתן ליצור משתנים מסוג זה כך שאפשר יהיה להציב בהם null, אך לא למדנו עדיין זאת.

  • השמת null: מציינים שהמשתנה לא מצביע על שום אובייקט.
  • השוואה ל-null: בודקים אם אובייקט קיים לפני שמשתמשים בו.
  • גישה לאובייקט שהוא null תגרום לשגיאה בזמן ריצה — NullReferenceException.
// השמת null — p לא מצביע על שום אובייקט
Point p = null;

// השוואה ל-null לפני שימוש
if (p == null)
{
    Console.WriteLine("No point");
}

if (p != null)
{
    Console.WriteLine("Point: " + p.X + ", " + p.Y);
}
⚠️ כאשר אנחנו ניגשים לאובייקט ויכול להיות שהוא null, תמיד נבדוק זאת לפני שאנחנו מנסים להשתמש בתכונה (property) או שיטה (method) של האובייקט.

2. מערך צפוף לעומת מערך דליל

מערך צפוף (Dense Array)

מערך דליל (Sparse Array)

חלק מהתאים מכילים null — "תאים ריקים".

[4]
null
[3]
P(3,4)
[2]
null
[1]
P(1,2)
[0]

תאים [1] ו-[3] ריקים — null

מערך דליל שימושי כאשר אנחנו רוצים להקצות מראש מקומות בגודל קבוע, אבל אנחנו לא תמיד משתמשים בכל המקומות. לפעמים הוא שימושי גם כאשר טווח האינדקסים שאנחנו צריכים הוא מאוד גדול אבל רובם ריקים. באופן כללי ניתן לומר שזו טכניקה שמשתמשים בה במקרים מאוד מסויימים — אבל רוב הזמן נשתדל לעבוד עם מערכים רגילים / צפופים.

3. יצירת מערך דליל (Sparse Array) והוספת אברים

נגדיר מחלקת Point פשוטה, ניצור מערך דליל בגודל 5, ונמלא רק חלק מהתאים. 

// הגדרת מחלקת Point
class Point
{
    public int X;
    public int Y;

    public Point(int x, int y)
    {
        X = x;
        Y = y;
    }
}

// יצירת מערך דליל (sparse array) בגודל 5
// כל התאים מאותחלים אוטומטית ל-null
Point[] sparse = new Point[5];

// הוספת אברים לתאים ספציפיים בלבד
sparse[0] = new Point(1, 2);
sparse[2] = new Point(3, 4);
sparse[4] = new Point(5, 6);

// sparse[1] ו-sparse[3] נשארים null
💡 כשיוצרים מערך של טיפוס הפניה עם new Point[5], כל התאים מקבלים אוטומטית את הערך null — מפני שזהו ערך ברירת המחדל (default) עבור טיפוסי הפניה.

למרות זאת, בשיעור זה לא נסמוך על ברירת המחדל — אם אנחנו רוצים מערך דליל, נאתחל בעצמנו קודם את כל האינדקסים ל-null במפורש.

4. דחיסת מערך דליל למערך צפוף

רוצים להפוך את המערך הדליל למערך צפוף — ללא null, ללא "חורים". עושים זאת ב-3 שלבים, ללא שינוי המערך המקורי (ההפך מ-in-place): 

// שלב 1: ספירת האברים שאינם null
int count = 0;
for (int i = 0; i < sparse.Length; i++)
{
    if (sparse[i] != null)
    {
        count++;
    }
}

// שלב 2: יצירת מערך צפוף חדש בגודל המדויק
Point[] dense = new Point[count];

// שלב 3: העתקת הערכים מהמערך הדליל למערך הצפוף
int j = 0;
for (int i = 0; i < sparse.Length; i++)
{
    if (sparse[i] != null)
    {
        dense[j] = sparse[i];
        j++;
    }
}

// התוצאה: dense הוא מערך צפוף ללא null

בסיום: sparse — לא השתנה (עדיין דליל), dense — מערך צפוף חדש עם 3 נקודות בלבד.
