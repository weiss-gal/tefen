א מטרת התוכנית

מנהל המשימות הוא תוכנית קונסול הכתובה ב-C# המאפשרת למשתמש לנהל רשימת משימות אישית.

התוכנית שומרת עד 10 משימות במערך קבוע בגודל 10. תא במערך שאינו מכיל משימה מכיל את הערך null. המשתמש מתקשר עם התוכנית דרך תפריט פשוט בשורת הפקודה.

כל משימה מכילה: תיאור, תאריך (שנה, חודש, יום כמספרים שלמים) ועדיפות.

⚠️ שימו לב: במקום השם Task נשתמש ב-MyTask — כיוון ש-Task הוא שם שמור ב-.NET.

בונוס 25% בדיקות תקינות קלט

הוסף בדיקות תקינות לכל קלטי המשתמש בפונקציה AddTask(MyTask[] tasks). יש לקרוא את הקלטים בסדר הבא:

שנה  →  חודש  →  יום

כך שניתן לאמת את היום לפי החודש והשנה שכבר הוזנו.

חוקי תקינות:

שנה — חייבת להיות מספר חיובי (גדול מ-0).

חודש — חייב להיות בין 1 ל-12.

עדיפות — חייבת להיות 1, 2 או 3.

יום — חייב להיות בין 1 למספר הימים המרבי בחודש. מספר הימים תלוי בחודש ובשאלה האם השנה היא שנת מעוברת:

חודשימים
1, 3, 5, 7, 8, 10, 1231
4, 6, 9, 1130
2 (שנה רגילה)28
2 (שנה מעוברת)29

כלל שנה מעוברת (Leap Year):

שנה היא מעוברת אם מתקיים אחד מהתנאים הבאים:

— מתחלקת ב-4 ואינה מתחלקת ב-100

— מתחלקת ב-400

לדוגמה: 2024 מעוברת (מתחלקת ב-4 ולא ב-100). 1900 אינה מעוברת (מתחלקת ב-100 אך לא ב-400). 2000 מעוברת (מתחלקת ב-400).

💡 רעיון למימוש: ניתן לשמור מערך של מספר הימים בכל חודש — int[] daysInMonth = { 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 } ואז לבדוק האם השנה מעוברת כדי להחליט אם לאפשר יום 29 בפברואר.

בונוס 10% עריכת תיאור משימה

הוסף לתפריט אפשרות נוספת לעדכון תיאור של משימה קיימת.

התוכנית תציג את המשימות, תבקש מספר משימה, ואז תבקש תיאור חדש ותעדכן אותו.

⚠️ שימו לב: כדי לאפשר שינוי תיאור לאחר יצירת האובייקט, יש להוסיף setter לשדה Description במחלקה MyTask.
