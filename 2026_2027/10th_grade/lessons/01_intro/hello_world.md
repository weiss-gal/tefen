# יצירת פרויקט C# ראשון - Hello World

במדריך הזה נלמד איך ליצור פרויקט קונסולה ב-C# בעזרת שורת הפקודה (cmd), נערוך את הקוד באמצעות Notepad, ונריץ אותו.

## שלב 1: פתיחת שורת הפקודה (cmd)

1. לחצו על מקש Windows.
2. הקלידו `cmd` ולחצו Enter.

## שלב 2: יצירת תיקייה לפרויקט

בעזרת שורת הפקודה, ניצור תיקייה חדשה ונעבור אליה:

```bash
mkdir HelloWorld
cd HelloWorld
```

## שלב 3: יצירת פרויקט קונסולה חדש

נשתמש בכלי ה-dotnet CLI כדי ליצור פרויקט קונסולה חדש:

```bash
dotnet new console
```

הפקודה הזו יוצרת בתוך התיקייה כמה קבצים, וביניהם קובץ בשם `Program.cs` - זהו קובץ הקוד הראשי של הפרויקט.

## שלב 4: עריכת הקובץ בעזרת Notepad

נפתח את הקובץ `Program.cs` בעזרת Notepad ישירות משורת הפקודה:

```bash
notepad Program.cs
```

יפתח חלון Notepad עם הקוד ההתחלתי. נמחק את התוכן הקיים ונכתוב במקומו את הקוד הבא:

```csharp
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello World, my name is Gal");
        }
    }
}
```

לאחר מכן נשמור את הקובץ (Ctrl+S) ונסגור את Notepad.

## שלב 5: הרצת התוכנית

נחזור לחלון שורת הפקודה ונריץ את הפקודה הבאה:

```bash
dotnet run
```

אם הכל הוגדר נכון, אמורה להופיע בחלון הפלט השורה הבאה:

```
Hello World, my name is Gal
```

שימו לב: כדאי להחליף את "Gal" בשם שלכם.

## סיכום

יצרנו פרויקט קונסולה חדש ב-C# בעזרת `dotnet new console`, ערכנו את קובץ הקוד באמצעות Notepad, והרצנו אותו עם `dotnet run`. כך נראה התהליך הבסיסי של כתיבה והרצה של תוכנית ב-C#.
