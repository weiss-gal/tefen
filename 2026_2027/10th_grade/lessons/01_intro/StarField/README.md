# סימולציית שדה כוכבים (Star Field) עם Canvas

פרויקט זה הוא אפליקציית WPF (חלונות גרפיים) שמדגימה שימוש ב-`Canvas` ליצירת סימולציית טיסה בשדה כוכבים, בדומה למסך שומר המסך הקלאסי.

## איך זה עובד

- לכל כוכב יש מיקום תלת-ממדי: `X`, `Y` (מיקום בצדדים) ו-`Z` (מרחק מהצופה).
- בכל "טיק" של טיימר (כ-60 פעמים בשנייה), ערך ה-`Z` של כל כוכב קטן - כלומר הכוכב "מתקרב" אלינו.
- המיקום על המסך מחושב באמצעות הטלה פרספקטיבית פשוטה: `screenX = centerX + (X / Z) * scale`, וכך גם עבור ציר ה-Y. ככל שה-Z קטן יותר (הכוכב קרוב יותר), הכוכב זז יותר מהר החוצה מהמרכז וגם מוצג גדול יותר.
- כאשר כוכב מגיע קרוב מדי למצלמה (Z קטן מאוד), הוא נוצר מחדש במרחק מקסימלי עם מיקום X,Y ואצבע צבע אקראיים חדשים - וכך הסימולציה נמשכת לנצח.
- כל כוכב מיוצג ע"י `Ellipse` על גבי `Canvas`, שהמיקום (`Canvas.Left`/`Canvas.Top`), הגודל והשקיפות (`Opacity`) שלו מתעדכנים בכל טיק - כוכבים קרובים גדולים ובהירים יותר, כוכבים רחוקים קטנים ועמומים יותר.
- לכל כוכב נבחר בזמן היצירה צבע אקראי מתוך פלטה ריאליסטית (`StarPalette`) המחקה את הפיזור האמיתי של סוגי כוכבים בשמיים: בעיקר לבן/לבן-חמים, ומיעוט של כוכבים כחולים-לוהטים וכוכבים אדומים-קרים. לכל כוכב יש גם ערך `Brightness` אקראי קטן שמוסיף גיוון עדין.
- החלון רץ במסך מלא ללא מסגרת (`WindowStyle="None"`, `WindowState="Maximized"`). לחיצה על **Esc** סוגרת את החלון.

## איך מריצים

מתוך תיקיית הפרויקט (`StarField`), בשורת הפקודה:

```bash
dotnet run
```

ייפתח חלון במסך מלא עם רקע שחור וכוכבים צבעוניים שנעים באיטיות כלפי חוץ מהמרכז, כאילו אנחנו טסים דרכם. לחיצה על Esc סוגרת את התוכנית.
